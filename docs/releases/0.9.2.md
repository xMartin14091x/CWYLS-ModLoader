# CWY:LS Mod Loader v0.9.2 · Dusk

**Pack Maker preview.** Create story subtitles and dubs in a browser while the game is running.
The mod API may still change before 1.0.

Unofficial fan project, not made, endorsed or supported by Nestopi. Requires the full Steam release
of *Chill With You: Lo-Fi Story*. The loader switches itself off on the free demo.

## For creators

- **Pack Maker: Dub & Subtitle Studio.** Open the mod console with **Ctrl+Shift+C** and enter `maker`.
  Create a language pack, restart the game once to load it, then browse story lines and write subtitles.
  Subtitle edits save automatically. Enter `maker stop` to stop Pack Maker.
- **Dub takes.** Record through your browser or import your own audio. Keep up to three takes per voiced
  line, listen and trim, then choose the take to put in the pack.
- **Try a line in game.** **Play my version in game** saves the subtitle and prepares the selected dub
  before playback. A subtitle-only version uses the original voice. The game must be running and ready
  to speak the line.
- **Voice-origin labels.** Set the pack default to **My own voice**, **AI-assisted** or **AI-generated**,
  with an override for individual takes. Confirm the voice and its origin before putting a take in the
  pack. Published audio carries its origin in `voice-provenance.json`.
- **Export a `.zip`.** Review checks for the manifest, subtitles, audio, voice disclosure, package size,
  line coverage and symbolic links. Failed checks block export; warnings need review. A dub without a
  voice label (copied in by hand or saved by the older voice upload) blocks export; one button labels them
  all with the pack's voice origin. Choose a version
  bump and add release notes. Creator take sources and backups are left out of the archive.

Follow the [Pack Maker guide](../guide/pack-maker.md) for the steps and storage limits.
The [porting guide](../guide/porting.md) and [outfit and texture guide](../guide/textures.md) are also new
since 0.9.1.

## For players

Pack Maker is included in the macOS and Windows player downloads. It starts only when requested.
To use a shared pack, unzip its pack folder into **`CWYLS Mods`** inside the game folder, then restart
the game. For a language pack, select its language in the game's settings. No translation or dub pack
is included with this release.

Download the zip for your system from [Releases](https://github.com/xMartin14091x/CWYLS-ModLoader/releases)
and follow the [installation steps](../../README.md#-install). Existing users choose **Install or update**.

## Fixes and safeguards

- Pack-added small-talk group IDs are held out of saves even when Pack Lines is disabled. The filter
  tracks the groups packs actually added; if the guard cannot start, those groups are not injected.
- Lines identified as paid DLC are hidden from Pack Maker and refused for editing, preview and export.
  DLC ownership checking is not connected yet, so those lines stay hidden even for owners.
- Pack Maker now attempts to bring the game window forward on Windows after starting a line.
- The local API no longer mistakes Windows' slow response on a free port for a port already in use.
- `helper.Data.WriteJson` writes a value read with `helper.Data.ReadJson` back as the same JSON. Objects
  used to come out as arrays of key/value pairs.
- Pack Maker's editor no longer flashes white when you switch pages.
- Installers refresh plugin file timestamps so BepInEx notices an update, and warn when another mod
  has replaced the bundled BepInEx version.

## Known limits

- This is a preview. The API is not frozen, and Pack Maker covers story subtitles and dubs. Game UI
  text, bulk dub import and subtitle round-trip are outside this preview's editor.
- Keep the game running while using Pack Maker. Newly created packs need one game restart.
- Browser recording needs microphone permission and browser audio support. Imported audio must be
  decodable by the browser.
- The DLC gate uses the markers in this build; compatibility with future game or DLC updates still
  needs checking against those builds.
- Packs cannot supply their own fonts yet. Thai support is built in, but some tone marks above tall
  consonants can sit slightly to the right, lower vowels under ฐ or ญ can touch the letter, and line
  breaks can split a word. See the [translation guide](../guide/translate.md).
- Intel Macs and other BepInEx mods alongside the loader have not been tested.
