# CWY:LS Mod Loader v0.9.3 · Dusk (hotfix)

**Hotfix for the game's 2.0.0 update (25 Nov 2026).** Same features as 0.9.2. The mod API may still change before 1.0.

Unofficial fan project, not made, endorsed or supported by Nestopi. Requires the full Steam release
of *Chill With You: Lo-Fi Story*. The loader switches itself off on the free demo.

## What changed

- **Paid DLC stays out of Pack Maker on game 2.0.0.** The update marks the new "Room & Cozy Activities
  Expansion" content in a new way, which 0.9.2 did not recognise, so Pack Maker listed it. 0.9.3 reads the
  game's own DLC flag and hides that content again everywhere the loader reaches it: Pack Maker's lists,
  editor, playback and export, `scene play`, and pack subtitles and dubs. It is hidden for everyone, DLC
  owners included, for now; editing DLC lines for owners comes in a later update. If the flag cannot be
  read, everything the game added after 2.0.0 is hidden instead.
- **Packs cannot reach paid content.** A content pack's rows that would replace, extend or use paid DLC lines,
  voices or groups are refused at load, and the log names them (ids only).
- **Works with game 2.0.0 again.** Pack line pools (click reactions, self-talk, timer voices, small talk), Satone's
  look commands, outfit textures and the pomodoro voice event follow the game's new code. On 0.9.2 with game 2.0.0
  they were switched off.
- **Made for game 2.0.0.** The loader and the example packs now name 2.0.0 as the game version they were
  checked against.
