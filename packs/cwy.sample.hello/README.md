# cwy.sample.hello (build output)

The sample code mod: Satone welcomes you back once per session when the room is ready, and the
console command `hello [name]` makes her greet you. `CwySampleHello.dll`, its `.pdb` and
`manifest.json` here are **copied by the build** of `mods-src/cwy.sample.hello/`; edit the source and
the manifest there, then `dotnet build mods-src/cwy.sample.hello -c Release`. See that folder's README.
